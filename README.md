# Amazon KDP — AI Publishing Project

This repository is the operating source of truth for building an **AI-assisted publishing business** on Amazon KDP.

The strategy is intentionally narrow:

1. **Fast catalog:** Christian/Bible large-print puzzle books
2. **Compounding IP:** one cozy-mystery fiction series

We research broadly, but we only scale categories after real sales/read-through data proves they deserve more production time.

## Operating principle

Every product goes through:

**Research → Product hypothesis → Create → QA → Publish → Measure → Improve / Scale / Kill**

We are not optimizing for number of uploads.

We are optimizing for:

**net contribution profit ÷ human hours invested**

## Non-negotiables

- Research the market before creating a book.
- Keep one clear audience and one clear commercial promise per product.
- Do not copy or closely paraphrase competitors.
- Check copyright/trademark/IP risk before publication.
- Disclose AI-generated content in KDP when current policy requires it.
- Use automated QA plus human QA.
- Order physical proofs for print products.
- Track actual post-launch performance.
- Scale winners; stop feeding weak products.
