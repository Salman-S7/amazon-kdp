# Quality, Compliance, and Production Checklist

Use this checklist for every title.

## 1. Market fit
- [ ] Primary audience is explicit.
- [ ] One clear commercial promise exists.
- [ ] At least 20–30 comparable titles were reviewed.
- [ ] Price, page count, reviews, publication date, formats, covers, descriptions, and customer complaints were recorded.
- [ ] We found evidence that newer entrants can compete.

## 2. Originality and rights
- [ ] No competitor text was copied or closely paraphrased.
- [ ] No competitor illustrations were reused.
- [ ] Cover does not imitate another book too closely.
- [ ] Trademark and copyright risks were reviewed.
- [ ] Logos, league/team branding, celebrity likenesses, song lyrics, characters, and brand names are licensed or excluded.
- [ ] Modern Bible-translation quotations are rights-cleared or omitted.
- [ ] Public-domain status is verified before relying on public-domain material.

## 3. AI use
- [ ] AI-generated text/images/translations are disclosed in KDP when required by current policy.
- [ ] Human editorial review was completed.
- [ ] Repetition and hallucination checks were completed.
- [ ] Facts were independently checked where factual accuracy matters.

## 4. Metadata
- [ ] Title on cover matches listing metadata.
- [ ] Subtitle matches listing metadata.
- [ ] Author/pen name is consistent.
- [ ] Series metadata is consistent.
- [ ] Keywords accurately describe the book.
- [ ] Categories accurately describe the book.
- [ ] No misleading sales-rank or promotional claims.
- [ ] No unauthorized brand/author references in metadata.

## 5. Interior QA
- [ ] Correct trim size.
- [ ] Correct margins/gutter.
- [ ] No clipped text.
- [ ] No accidental blank pages.
- [ ] No duplicate pages.
- [ ] Page numbering is correct.
- [ ] Fonts are embedded/print-safe.
- [ ] Black-and-white graphics reproduce clearly.
- [ ] Table of contents works where relevant.
- [ ] Kindle reflow was checked where relevant.

## 6. Puzzle-specific QA
- [ ] Every listed word is present.
- [ ] Every solution is correct.
- [ ] No duplicate puzzle grids.
- [ ] No malformed characters.
- [ ] Difficulty matches product promise.
- [ ] Physical font size is genuinely readable.
- [ ] Reused vocabulary is controlled across books.

## 7. Fiction-specific QA
- [ ] Timeline is consistent.
- [ ] Character details are consistent.
- [ ] Geography/location logic is consistent.
- [ ] Mystery clues support the solution.
- [ ] Red herrings are fair.
- [ ] Killer/motive/method all make sense.
- [ ] No unresolved contradiction.
- [ ] Prose does not contain obvious AI repetition or generic filler.
- [ ] Ending satisfies the central book promise.

## 8. Cover QA
- [ ] Readable at thumbnail size.
- [ ] Correct genre/product signal.
- [ ] Series branding is consistent where applicable.
- [ ] Spine text fits.
- [ ] Barcode area is clear.
- [ ] No unlicensed imagery.
- [ ] No misleading similarity to competitors.

## 9. Physical proof
- [ ] Proof copy ordered.
- [ ] Gutter checked.
- [ ] Font size checked physically.
- [ ] Cover darkness/contrast checked.
- [ ] Spine alignment checked.
- [ ] Page order checked.
- [ ] Cutoff/bleed checked.
- [ ] Answer keys checked in print.

## 10. Post-launch tracking
Track:
- units sold
- KU pages read
- gross royalty
- ad spend
- ad-attributed revenue
- estimated contribution profit
- reviews
- rating
- BSR trend
- keyword positions
- price changes
- cover changes
- conversion changes
- production hours

Primary portfolio metric:
**net contribution profit ÷ human hours invested**
